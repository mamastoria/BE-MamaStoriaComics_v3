Comic Title Generation - Troubleshooting Guide

## Problem: Title is NULL after creating story idea

### Expected Behavior (BY DESIGN)

When you call POST /api/v1/comics/story-idea:

1. ✅ Comic is created immediately with status PENDING
2. ✅ Title is NULL (not generated yet)
3. ✅ Script generation is queued in background
4. ⏳ AI generates script + title (takes 30-120 seconds)
5. ✅ Title is populated when script generation completes

### Timeline

```
Time 0s:  POST /story-idea
          → Response: {title: null, status: "PENDING"}

Time 5s:  Job processor picks up comic
          → Status: "GENERATING_SCRIPT"

Time 60s: AI finishes script generation
          → Title populated: "Istriku Seorang CEO"
          → Status: "SCRIPT_READY"
```

### How to Check Title

#### Option 1: Poll Status Endpoint (Recommended)

```bash
# Get comic status
GET /api/v1/comics/{id}/draft/status

# Response when ready:
{
  "data": {
    "id": 327,
    "title": "Istriku Seorang CEO",  # ✅ Title now populated
    "status": "script_ready",
    "summary": "...",
    "panels": [...]
  }
}
```

#### Option 2: Use SSE Stream

```javascript
// Frontend: Listen for real-time updates
const eventSource = new EventSource("/api/v1/comics/327/stream-status");

eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log("Title:", data.title); // Updates when ready
  console.log("Status:", data.status);

  if (data.status === "SCRIPT_READY") {
    eventSource.close();
  }
};
```

### Troubleshooting

#### If title is still NULL after 2+ minutes:

1. **Check comic status:**

   ```bash
   GET /api/v1/comics/327/draft/status
   ```

2. **Check for errors:**
   - If status = `SCRIPT_FAILED`: Script generation failed
   - Check `last_error_message` field for details

3. **Trigger recovery:**

   ```bash
   # Auto-recover failed comics
   POST /api/v1/worker/recover-failed-jobs
   ```

4. **Check job processor logs:**
   ```bash
   # Look for script generation errors
   grep "Comic #327" /var/log/app.log
   ```

### Common Causes of NULL Title

1. **Script generation still in progress** ⏳
   - Solution: Wait or poll status endpoint

2. **Script generation failed** ❌
   - Check status = "SCRIPT_FAILED"
   - Check error logs
   - Run recovery endpoint

3. **Job processor not running** 🔧
   - Check cron job is configured
   - Manually trigger: POST /api/v1/jobs/process

4. **AI model error** 🤖
   - Check Vertex AI quota
   - Check API credentials
   - Retry via recovery

### Frontend Implementation Example

```dart
// Flutter: Poll for title
Future<void> waitForTitle(int comicId) async {
  for (int i = 0; i < 30; i++) {  // Max 2 minutes
    await Future.delayed(Duration(seconds: 4));

    final response = await dio.get('/api/v1/comics/$comicId/draft/status');
    final data = response.data['data'];

    if (data['title'] != null) {
      print('✅ Title ready: ${data['title']}');
      return;
    }

    if (data['status'] == 'script_failed') {
      print('❌ Script generation failed');
      throw Exception('Script generation failed');
    }
  }

  throw TimeoutException('Title generation timeout');
}
```

### Summary

**Title being NULL immediately after POST /story-idea is NORMAL.**

You need to:

1. ✅ Wait for script generation (30-120 seconds)
2. ✅ Poll status endpoint to get title
3. ✅ Or use SSE stream for real-time updates
4. ✅ Handle SCRIPT_FAILED status gracefully
