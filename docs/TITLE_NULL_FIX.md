# Fix: Title NULL Error - Comprehensive Solution

## Problem Statement

**Issue:** Comic title remains NULL even after long wait time, causing frontend errors.

**Root Cause:**

1. Title is only generated by AI during script generation
2. If script generation fails → title stays NULL
3. Frontend expects title to always exist → crashes when NULL

## Solution Implemented

### 🔧 **Three-Layer Fallback System**

#### Layer 1: Immediate Fallback (On Creation)

**File:** `app/services/comic_service.py`

```python
# When creating comic from story idea
comic = Comic(
    ...
    # ✅ Set fallback title IMMEDIATELY
    title=(story_idea[:80] if story_idea else "Untitled Comic").strip(),
    synopsis=story_idea[:500] if story_idea else None,
    summary=story_idea[:500] if story_idea else None
)
```

**Result:**

- ✅ Title is NEVER null from the start
- ✅ Uses first 80 chars of story_idea as title
- ✅ Frontend can display comic immediately

#### Layer 2: AI-Generated Title (On Success)

**File:** `app/services/job_processor.py` (line 265)

```python
# After successful script generation
ai_title = global_data.get("comic_title") or ...
comic.title = ai_title or (comic.story_idea[:100] if comic.story_idea else "Untitled")
```

**Result:**

- ✅ AI generates proper title
- ✅ Replaces fallback with AI title
- ✅ Better quality title

#### Layer 3: Fallback on Failure

**File:** `app/services/job_processor.py` (line 296-299)

```python
# When script generation FAILS
if not comic.title:
    fallback_title = (comic.story_idea[:80] if comic.story_idea else "Untitled Comic").strip()
    comic.title = fallback_title

# Also set synopsis/summary fallbacks
if not comic.synopsis and comic.story_idea:
    comic.synopsis = comic.story_idea[:500]
if not comic.summary and comic.story_idea:
    comic.summary = comic.story_idea[:500]
```

**Result:**

- ✅ Even on SCRIPT_FAILED, title is set
- ✅ No NULL errors in frontend
- ✅ User can still see their comic

```
  ↓
Script generation FAILS
  ↓

  ↓
Frontend crashes: "Cannot read property of null"
```

### ✅ After (Fixed):

```

  ↓
Response: {title: "istriku seorang ceo", status: "PENDING"}  ← FALLBACK TITLE
  ↓

  ↓
Comic updated: {title: "Istriku Seorang CEO", status: "SCRIPT_READY"}  ← AI TITLE
```

**OR if script fails:**

```
POST /story-idea: "istriku seorang ceo"
  ↓

  ↓

  ↓

  ↓
Frontend works fine, shows fallback title
```
